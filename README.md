# Лабораторная работа № 4. Telegram-бот «Погода»

## Цель

Разработать на Python Telegram-бота, который получает текущую погоду через внешний API, принимает запросы несколькими способами и сохраняет пользовательские настройки.

## Что умеет бот

| Действие в личном чате | Результат |
| --- | --- |
| `/start` | Справка и кнопка отправки геопозиции |
| `Казань` или `/weather Казань` | Текущая погода в указанном городе |
| Кнопка «Отправить геопозицию» | Текущая погода по координатам |
| `/setcity Казань` | Сохранение города для текущего пользователя |
| `/weather` | Текущая погода в сохранённом городе |

Ответ содержит температуру, ощущаемую температуру, влажность и скорость ветра. Если у нескольких мест одинаковое название, бот берёт первый результат поиска и показывает регион и страну, когда они доступны.

## Как устроено решение

Весь код бота находится в `bot.py`. Библиотека `python-telegram-bot` получает сообщения через long polling. При вводе города бот отправляет его название в API геокодирования Open-Meteo и получает координаты. При отправке геопозиции координаты уже есть в сообщении Telegram. Затем бот запрашивает текущую погоду по этим координатам и формирует ответ из JSON.

В SQLite хранится одна запись на пользователя. Ключом служит Telegram ID, а значением — название сохранённого города и его координаты. База сохраняется на диске. Координаты, отправленные кнопкой геопозиции, используются для одного запроса.

Названия длиной менее двух или более ста символов отклоняются. При неизвестном городе бот просит проверить название. Для запроса к Open-Meteo задан тайм-аут. При сетевой ошибке, некорректном ответе API или ошибке SQLite бот сообщает о проблеме пользователю.

## Локальный запуск

Нужны Python 3.10 или новее и токен от BotFather. Команды для PowerShell из каталога проекта:

```powershell
python -m pip install -r requirements.txt
$env:TELEGRAM_BOT_TOKEN = "ВАШ_ТОКЕН"
python bot.py
```

В Linux переменную можно задать командой `export TELEGRAM_BOT_TOKEN='ВАШ_ТОКЕН'`. Файл базы `weather.sqlite3` создаётся в рабочем каталоге. Для запуска второй копии нужен отдельный токен, поскольку Telegram допускает один процесс long polling на бота.

## Сценарии для демонстрации

1. Ввести `Казань` и сравнить результат с `/weather Казань`.
2. Отправить геопозицию и проверить ответ с погодой по координатам.
3. Сохранить город через `/setcity Казань`, перезапустить процесс и вызвать `/weather`.
4. Ввести заведомо неизвестный город и проверить сообщение об ошибке.

## Подготовка к защите

1. **Постановка задачи.** Определить вопрос, исходные данные и критерий проверки результата.
2. **Поиск данных.** Подобрать источник и оценить его актуальность, полноту, формат и условия использования.
3. **Подготовка.** Проверить пропуски, типы, дубликаты и единицы измерения. Преобразовать данные к формату анализа.
4. **Исследование.** Изучить распределения, сводные показатели, выбросы и связи между признаками.
5. **Визуализация.** Выбрать график по вопросу, подписать оси и указать единицы измерения.
6. **Датасет.** Набор данных для одной задачи. В таблице строки обычно представляют наблюдения, а столбцы — признаки.
7. **NumPy.** Библиотека для численных вычислений. Поддерживает многомерные массивы и векторные операции.
8. **Массивы NumPy.** У массива есть форма и тип элементов. Можно взять срез `a[1:3]` или выбрать значения по маске `a[a > 0]`.
9. **Математические функции NumPy.** `np.mean(a)` вычисляет среднее, `np.std(a)` — стандартное отклонение, `np.sqrt(a)` — корни поэлементно.
10. **Pandas.** Библиотека для чтения, преобразования и анализа табличных данных.
11. **Series.** Одномерный набор значений с индексом. Например, `df["temperature"]` возвращает столбец.
12. **DataFrame.** Таблица с индексами строк и столбцов. Разные столбцы могут иметь разные типы.
13. **Подготовка в Pandas.** `isna()` находит пропуски, `drop_duplicates()` удаляет дубликаты, `astype()` меняет тип данных.
14. **Исследование в Pandas.** `describe()` даёт сводку, `groupby()` группирует данные, `corr()` оценивает корреляцию.
15. **Matplotlib.** Библиотека для построения и сохранения графиков.
16. **Основные графики.** `plot()` показывает изменение величины, `bar()` сравнивает категории, `hist()` показывает распределение, `pie()` — доли целого.
17. **Другие графики.** `scatter()` показывает связь двух величин, `boxplot()` — медиану, квартили и выбросы, `psd()` — спектральную плотность мощности сигнала.
18. **API.** Описанный интерфейс, через который одна программа обращается к функциям или данным другой.
19. **API в Python.** В боте `urlencode()` кодирует параметры, `urlopen()` отправляет HTTPS-запрос, а `json.load()` читает ответ.
20. **Telegram-бот на Python.** Регистрируем бота в BotFather, получаем токен и добавляем обработчики. Long polling получает обновления от Telegram, а обработчик отвечает на сообщение.
